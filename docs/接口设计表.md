# 后端接口设计表

> 系统: 基于Prompt工程的上市公司财报解读与行业对标系统
> 端口: 8091 | 统一前缀: `/api` | 统一响应: `{"code":"0","message":"success","data":{...}}`

## 通用说明

- **code = "0"** 表示成功; 非 0 为业务错误码(见 `com.fycx.common.ErrorCodeEnums`)
- 全部参数/返回均为 JSON(UTF-8), 金额单位: 元, 指标单位见各指标定义
- 财务接口需先执行 `POST /api/finance/recalc` 生成指标与对标数据

## 1. 财务模块 `/api/finance`

### 1.1 行业列表
`GET /api/finance/industries`
```json
// 返回 data: [{"industryId":3,"industryCode":"C15","industryName":"酒、饮料和精制茶制造业","companyCount":8}]
```

### 1.2 公司分页查询
`GET /api/finance/companies?keyword=&industryId=&status=&page=1&size=10`
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| keyword | string | 否 | 股票代码/简称/全称模糊匹配 |
| industryId | int | 否 | 行业过滤 |
| status | int | 否 | 默认 1(正常) |
| page / size | int | 否 | 分页, 默认 1/10, size≤100 |

返回 `data: {total, page, size, list:[CompanyVO]}`

### 1.3 公司详情
`GET /api/finance/companies/{companyId}` → `data: CompanyVO`

CompanyVO: `{companyId, stockCode, stockName, fullName, exchange, industryId, industryName, listDate, status}`

### 1.4 财务画像
`GET /api/finance/profile?companyId=17&fiscalYear=2025&reportPeriod=年报`
返回 `data: {company, fiscalYear, reportPeriod, industryName, items:[{itemCode,itemName,reportType,unit,amount}], indicators:[{indicatorCode,indicatorName,dimension,unit,value,betterDirection}], valuation:{snapshotDate,closePrice,marketCap}}`

### 1.5 多年度指标趋势
`GET /api/finance/trend?companyId=17&indicators=roe,gross_margin,pe&startYear=2021&endYear=2025`
- indicators 逗号分隔, 缺省返回全部 12 项
- 返回 `data: [{indicatorCode, indicatorName, unit, points:[{year,value}]}]`

### 1.6 行业对标(核心)
`GET /api/finance/benchmark?companyId=17&fiscalYear=2025&reportPeriod=年报`
返回 `data: {company, fiscalYear, reportPeriod, industryName, items:[BenchmarkItemVO]}`
BenchmarkItemVO: `{indicatorCode, indicatorName, dimension, unit, betterDirection, companyValue, avgValue, medianValue, p25, p75, stdDev, companyCount, percentile, score, rank, total}`
- percentile: 原始百分位(0-100, 值越大数值越高)
- score: 方向调整评分(0-100, 越高越优; lower_better 指标 = 100 - percentile)
- rank: 行业排名(1=最优) / total: 行业公司数

### 1.7 行业指标排名
`GET /api/finance/ranking?industryId=3&fiscalYear=2025&indicatorCode=roe&order=desc&limit=20`
- order: asc/desc(缺省按指标方向自动)
- 返回 `data: [{companyId, stockCode, stockName, value, percentile, rank}]`(按 rank 升序)

### 1.8 多条件交叉筛选(AND)
`POST /api/finance/screening`
```json
{
  "industryId": 3,                 // 可选, 缺省全市场
  "fiscalYear": 2025,
  "reportPeriod": "年报",
  "conditions": [
    {"indicatorCode": "roe", "operator": "gt", "value": 25},
    {"indicatorCode": "asset_liability_ratio", "operator": "lt", "value": 35},
    {"indicatorCode": "pe", "operator": "between", "value": 10, "value2": 35}
  ],
  "page": 1, "size": 50
}
```
operator 支持: `gt / gte / lt / lte / between / pct_gt(行业百分位高于) / pct_lt(行业百分位低于)`
返回 `data: {total, conditionCount, companies:[{companyId, stockCode, stockName, industryName, matchedCount, details:[{indicatorCode, indicatorName, operator, value, value2, actualValue, passed}]}]}`

### 1.9 重算指标与行业对标
`POST /api/finance/recalc` body 可选 `{"industryId":1,"fiscalYear":2025}`(缺省全量)
返回 `data: {indicatorCount, benchmarkCount, message}`
流程: 原始数据 → 指标计算引擎(12项) → 行业对标统计引擎(均值/中位数/标准差/P25/P75)

## 2. AI 模块 `/api/ai`

### 2.1 Prompt 模板列表
`GET /api/ai/templates` → `data: [{templateId, templateType, templateContent, version, enabled}]`

### 2.2 生成财报解读简报
`POST /api/ai/report`
```json
{"companyId": 17, "fiscalYear": 2025, "reportPeriod": "年报", "extraInstruction": "重点关注经营现金流"}
```
流程: 取行业对标数据 → 序列化为数据上下文 JSON → 组装三层 Prompt
(角色设定 + 数据注入 + 输出约束) → 调用 LLM(openai 兼容) → 落库
返回 `data: AiReport {reportId, companyId, fiscalYear, reportPeriod, reportType:"brief", userQuestion, aiAnswer(Markdown), context(注入数据JSON, 防幻觉审计), createTime}`

### 2.3 上下文感知追问对话
`POST /api/ai/chat`
```json
{
  "companyId": 17, "fiscalYear": 2025, "reportPeriod": "年报",
  "question": "茅台的毛利率和ROE在行业里处于什么水平?",
  "history": [{"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}]
}
```
返回 `data: AiReport {reportType:"chat", ...}`

### 2.4 报告记录
`GET /api/ai/reports?companyId=17&page=1&size=10` → `data: {total, page, size, list:[AiReport]}`
`GET /api/ai/reports/{reportId}` → `data: AiReport`

### 2.5 LLM 配置与降级
- `ai.provider=mock`: 无需 API Key, 由规则引擎基于注入数据生成确定性报告/回答(演示与离线可用)
- `ai.provider=openai`: 调用 OpenAI 兼容接口(DeepSeek/通义/智谱等), 失败自动降级 mock
- 配置项: `ai.base-url / ai.api-key / ai.model / ai.temperature / ai.timeout-seconds`

## 3. 错误码 (ErrorCodeEnums)

| code | 说明 |
|---|---|
| COMPANY_NOT_EXIST | 公司不存在 |
| DATA_NOT_FOUND | 未找到财务数据 |
| INVALID_YEAR / REPORT_TYPE_ERROR | 年份/报告期无效 |
| INDICATOR_NOT_FOUND | 指标未找到 |
| BENCHMARK_NOT_FOUND | 行业对标数据未找到 |
| NO_INDICATOR_DATA | 暂无指标数据, 请先执行 recalc |
| SCREENING_NO_CONDITION | 筛选条件不能为空 |
| LLM_CALL_FAILED / AI_SERVICE_ERROR | 大模型/AI 服务异常 |
| TEMPLATE_NOT_FOUND | 提示词模板未找到 |
| INVALID_PARAM | 参数无效 |
| SYSTEM_ERROR | 系统内部错误 |
