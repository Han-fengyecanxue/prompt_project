# 后端实现摘要

> 本文只记录后端关键实现、数据口径和验证状态。项目启动、配置与接口示例以 [README](../README.md) 和 [接口设计表](接口设计表.md) 为准。

## 系统结构

后端基于 Spring Boot 3.4、MyBatis 和 MySQL。财务链路为：原始报表数据 → 指标计算 → 同行业统计 → 查询/筛选；AI 链路为：行业对标数据 → 三层 Prompt → mock 或 OpenAI 兼容模型 → 报告留档。

主要模块：

- `service/calc/IndicatorCalcEngine`：计算财务比率、增长率和估值指标。
- `service/calc/BenchmarkCalculator`：计算均值、中位数、分位数、标准差、百分位和方向排名。
- `service/impl/FinanceServiceImpl`：读入原始科目、按年度计算并保存指标与行业基准。
- `service/impl/AiServiceImpl`：组装数据上下文、调用模型或 mock，并保存报告。
- 九张业务表的定义见 `sql/01_schema.sql`；采集程序见 `sql/fetch_real_data.py`。

## 指标口径

| 指标 | 当前计算口径 |
|---|---|
| ROE | 归母净利润 / 平均**归属于母公司股东的权益** × 100% |
| 毛利率 | (营业收入 - 营业成本) / 营业收入 × 100% |
| 归母净利率 | 归母净利润 / 营业收入 × 100% |
| 营收、利润增长率 | (本期值 - 上期值) / 上期值绝对值 × 100% |
| 资产负债率 | 总负债 / 总资产 × 100% |
| 流动、速动比率 | 流动资产 / 流动负债；(流动资产 - 存货) / 流动负债 |
| 现金流质量 | 经营现金流净额 / 净利润 |
| PE、PB | 总市值 / 归母净利润；总市值 / **归属于母公司股东的权益** |

行业基准按行业、年度、指标分组；分位数采用线性插值。每行业只有 8 家样本，研究结论应限定在当前样本，不外推为整个行业规律。

### ROE / PB 分母口径（2026-10 修正）

财务数据中有两个权益科目，**不可混用**：

| 科目 | item_id | 含义 |
|---|---|---|
| `total_equity` | 17 | 所有者权益合计 = 归母权益 + 少数股东权益 |
| `total_equity_parent` | 23 | 归属于母公司股东的权益（归母权益） |

修正前 ROE/PB 误用 `total_equity`（合计），而分子是"归母"口径，分子分母不匹配，会**系统性低估** ROE/PB。
修正后统一使用 `total_equity_parent`。实测影响（24 家公司 2021–2025 共 120 个公司年度）：

| 指标 | 平均变化 | 中位变化 | 最大变化 | 相对变化 >5% 的样本 | 相对变化最大 |
|---|---|---|---|---|---|
| ROE | +0.72 pp | +0.17 pp | +5.20 pp | 23 个（19%） | 22.9% |
| PB | +0.22 | +0.07 | +2.25 | 25 个（21%） | 22.9% |

偏差方向恒为低估（因合计权益 ≥ 归母权益），且与公司少数股东权益规模正相关：
立讯精密、复星医药、迈瑞医疗、生益科技受影响最大；今世缘、云南白药、工业富联等几乎不受影响。

> 该口径修正由 `CalculationEnginesTest#roeAndPbUseParentEquityInsteadOfTotalEquity` 守护，防止回退。

## 数据注意事项

- 采集器现已区分缺失值和有效零值：缺失科目不入库并列入缺失清单，零值正常保留。
- 已提交的 `sql/03_real_data.sql` 不会因采集器修复自动更新。重新生成前先备份并检查缺失清单；生成的 SQL 会清理原始数据、估值快照、指标、基准和报告表。
  采集器输出路径现可用 `--out` 指定，建议先输出到临时文件核对差异再替换。
- **历史股本已核实**：`market_cap = 当年年末收盘价 × 当年年报股本`。用 `market_cap / close_price`
  反推的隐含股本与东方财富接口 `SHARE_CAPITAL` 逐年吻合（如中际旭创 8.001→8.028→11.212 亿股、
  云南白药 12.83→17.97 亿股、智飞生物 16.00→24.00 亿股），未走"当前股本近似"降级路径。
  因此**历史 PE/PB 可以作为论文结果使用**。
- 指标计算遇到缺失输入或零分母时不产出该指标，不以零代替；ROE/PB 缺少归母权益时同样不产出。
- 采集器现共采集 **23 个报表科目**（新增第 23 项"归属于母公司股东的权益"）。修改采集字段后需重跑采集与
  `POST /api/finance/recalc`，否则 `financial_indicator` 与原始数据会不一致。
- **已知历史产物**：`sql/03_real_data.sql` 由采集器修复前生成，其中包含 194 行"接口未返回即写 0"的记录
  （交易性金融资产 120 行、短期借款 42 行、应收票据 31 行、应收账款 1 行）。这 4 个科目**不参与任何指标计算**，
  对指标、行业基准与 AI 报告无影响；如后续整体重采，这些行会自然消失。

## 验证状态

```powershell
cd backend
.\mvnw.cmd -o -Dtest=CalculationEnginesTest test
py -3 -m unittest discover -s tests -v
```

当前测试覆盖指标公式、零分母、行业统计、采集缺失值处理和数值引用筛查。它们不等同于全接口集成测试；论文数据仍须经年报抽查与独立标注。研究流程见 [真实数据论文研究指南](Prompt工程深化研究与系统扩展方案.md)。
