# 真实财报数据论文研究指南

本文只保留论文研究所需的方法、数据检查和操作步骤。系统安装与 API 配置见 [README](../README.md)；后端计算口径见 [技术文档](技术文档.md)。

## 研究问题

建议聚焦一个可检验问题：**在上市公司财报解读任务中，提供真实财务数据和输出约束，是否能减少模型的错误数字引用，并保持报告结构与可读性？**

比较的是 Prompt 条件，不是“模型有无金融能力”。实验前登记假设和指标，不预写预期结果；分析结论以真实实验数据为准。

## 数据方案

**分析单位**：公司 × 财年 × 报告期。当前数据库包含 3 个行业、24 家公司、2021—2025 年数据；行业内各 8 家，属于小样本案例研究。

**推荐主样本**：先以 2021—2024 年作为主分析期，共 96 个公司年度；2025 年数据作为扩展样本，完成披露状态、缺项和年报抽查后再纳入。若调用预算有限，固定随机种子，在每个行业抽 4 家、每家取 2022—2024 年，得到 36 个公司年度试验样本；不要根据结果挑样本。

**数据核验**：

1. 运行 `py -3 sql/fetch_real_data.py --dry-run`，记录缺失科目、估值缺口和异常同比；缺失值不能按零解释。
2. 从巨潮资讯等正式年报抽查关键科目，至少覆盖每个行业、多个年份和存在异常的公司；保存报告名称、页码、单位及核对记录。
3. 统一合并报表/报告期/币种单位口径，检查收入、成本、利润、资产负债、现金流及股本字段。保留抓取日期和数据版本。
4. 修复采集器后，旧 `03_real_data.sql` 仍是旧快照。生成新 SQL 会清理已有数据表；先备份并审阅差异，确认后再导入并调用 `/api/finance/recalc`。

**指标边界**：当前估值股本可能使用当前股本近似值，未核实前排除 PE/PB 主分析；ROE 分母字段须确认是归母权益还是总权益。亏损导致的负 PE、负净利润下的现金流质量比率，以及缺失数据，均应预先定义为排除或单独分析，不能解释成正常排序。

## Prompt 对照实验

采用同一批公司年度、同一财务上下文、同一模型版本与生成参数，逐组改变 Prompt：

| 组别 | 输入条件 | 用途 |
|---|---|---|
| A | 角色设定，不提供财务上下文 | 无数据锚定基线 |
| B | 角色设定 + 系统计算的财务上下文 | 测数据锚定增量 |
| C | B + 明确禁止无依据数字、固定章节和缺数规则 | 测输出约束增量 |

固定问题文本、温度、最大输出长度和系统版本；记录模型名称/版本、日期、Prompt 全文、上下文 JSON、生成参数、原始回答、耗时和 token/费用。每个公司年度每组至少重复 3 次，随机打乱调用顺序。mock 是确定性功能测试，不作为真实大模型实验组。

项目的 `ai_report` 当前没有保存模型版本和 Prompt 版本；实验期应另存不可变的 `runs.csv` 或 JSONL，不能只依赖数据库报告记录。

## 评价与分析

- **数字事实准确率**：逐条标注报告中的财务数值，核对指标、年度、单位和年报来源。准确率 = 正确数字主张数 / 全部可核验数字主张数；同时报告每份报告的无依据/错误数字数。
- **覆盖率**：报告实际讨论的目标指标数 / 任务要求讨论的指标数，避免模型通过少说数字获得虚高准确率。
- **结构合规率**：是否包含规定章节、缺失项是否明示、是否超出长度要求。
- **语义质量**：两名评审者在不知道实验组别的情况下按统一量表评分；抽样复核数字来源并报告评审一致性。
- **成本与时延**：报告每组调用费用、输入/输出 token 和生成耗时。

`report_validator.py` 只能做候选数字筛查，不能替代年报核对或人工标注；无指标归属的数字和跨句关系都可能让规则评分失真。先用人工标注样本估计筛查器的漏报/误报，再决定是否可用于批量预筛。

同一公司年度在 A/B/C 中成对比较；报告样本量、缺失与排除规则、均值/中位数及置信区间。可用按公司聚类的 bootstrap 估计区间；小样本不宜只报告显著性，也要报告差异大小和限制。

## 执行清单

1. 固定主样本、财务口径、Prompt 三组和标注手册。
2. 完成数据核验，生成指标与行业对标；保存 SQL、代码版本和数据文件校验值。
3. 用少量样本试跑，检查采集和标注规则；确认后冻结方案，再跑全量样本。
4. 人工复核数字主张，汇总 `runs.csv`，再更新 `eval_data.csv` 和图表。现有 `eval_data.csv` 中的数值为示意数据，旧 mock 结果使用旧校验口径，均不能作为论文实测结果。
5. 报告研究问题、样本来源、排除项、模型版本、Prompt、指标定义、统计方法、结果和局限；不把提示词约束描述成“彻底消除幻觉”。

建议保留的实验文件：数据字典、年报核验表、Prompt 版本、逐次运行记录、人工标注表、分析脚本和最终图表。这样才能从论文中的一个结果追溯回具体输入与来源。
